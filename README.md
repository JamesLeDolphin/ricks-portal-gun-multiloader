# Rick's Portal Gun

Adds the portal gun from popular sci-fi series Rick and Morty. This project uses [Multiloader Template](https://github.com/jaredlll08/MultiLoader-Template) to ease the development for multiple modloaders.

## Features
### 1. Portal gun
The main attraction of this mod! This tool helps you cross between dimensions with a simple portal.
